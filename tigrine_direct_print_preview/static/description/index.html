Direct Print Preview

Say goodbye to thousands of useless PDFs in your Downloads folder

Overview

Every time you print an invoice, sale order, picking slip or any Odoo report, a PDF file is automatically downloaded. Over time, this clutters your computer with hundreds or thousands of unnecessary files. This module changes that behavior: instead of downloading the PDF, the browser’s native print dialog opens immediately. You can still save the PDF manually if needed, but the default flow respects your disk space and your time.

How It Works

  1. Click on any Print action
  2. PDF is generated on the server
  3. A new browser tab opens with the PDF
  4. The print dialog appears automatically
  5. Temporary tab closes – no file saved

No configuration required.
